# PM Corrective Rules — Cycle 011

- PR repair gates take priority over broad feature expansion when Codex blockers are present.
- Cursor agents may perform Jira read/write/edit operations only when explicitly assigned and must record those operations in cycle reports.
- Maintain 10–20 substantive tasks per agent, with 12–16 preferred.
- Product file changes must map to product Jira stories; governance-only Jira updates are insufficient when product code changes.
- Do not mark product stories Done unless full source DOD is met.
