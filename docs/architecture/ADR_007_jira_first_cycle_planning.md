# ADR-007 Jira-First Cycle Planning

## Status
ACCEPTED

## Context
Prompt planning quality degrades when tasks are generated without current Jira backlog truth.

## Decision
Use Jira as primary planning input for cycle scope and readiness.

## Rationale
Jira-first planning aligns execution with tracked commitments and reduces fabricated or stale scope.

## Consequences
Planning can block when Jira auth or issue hygiene is poor; governance requires reliable Jira sync workflows.
