# Recommendation Export Format

This document defines the current recommendation export contracts for Epic E05.

## Markdown Export

Markdown export is generated by `export_recommendation_markdown(...)` and organized into spec-aligned sections:

- Header with keyword name, tag, score, and niche
- `Viability Assessment`
- `Gig Title Options`
- `Packages` table (`Basic`, `Standard`, `Premium`)
- `Differentiation Angle`
- `FAQ`
- `Buyer Persona`
- `Thumbnail Direction`
- `Red Flags`
- Footer with generated timestamp, LLM cost, and completeness ratio

Missing task outputs are rendered with a fallback sentence instead of dropping sections.

## JSON Export

JSON export is generated by `export_recommendation_json(...)` and uses an envelope with two top-level keys:

- `metadata`
- `outputs`

`metadata` fields:

- `keyword_id`
- `keyword_text`
- `niche_id`
- `niche_name`
- `tag`
- `final_score`
- `generation_complete`
- `completeness_ratio`
- `llm_cost_usd`
- `generated_at` (ISO 8601 string)
- `export_schema_version` (`1.0`)

`outputs` fields:

- `gig_titles`
- `tag_sets`
- `package_structure`
- `description_outline`
- `faq_entries`
- `differentiation_angle`
- `buyer_persona`
- `thumbnail_direction`
- `upsell_structure`
- `red_flags`
- `niche_viability_assessment`

Wrapper models are flattened where the external export contract expects arrays:

- `gig_titles` -> list of title objects
- `tag_sets` -> list of tag-set arrays
- `faq_entries` -> list of FAQ objects
- `upsell_structure` -> list of upsell objects

All Pydantic payloads are serialized using `model_dump(mode="json")`, so `None` is preserved as JSON `null`.

## CLI Usage

Single recommendation export:

```bash
python run.py export-recommendation --keyword-id 101 --format markdown
python run.py export-recommendation --keyword-id 101 --format json
python run.py export-recommendation --keyword-id 101 --format json --output data/exports/keyword-101.json
```

Bulk export:

```bash
python run.py export-all-recommendations --run-id run-123 --format markdown --output-dir data/exports
python run.py export-all-recommendations --format json --output-dir data/exports
```

Summary:

```bash
python run.py recommendations-summary
```
